Сервис моделирования трасс подключения к тепловым сетям 
1. Контекст и актуальность задачи
За январь –июль 2026 года в Москве введено 8,1 млн кв. м недвижимости. Новые здания 
необходимо подключать к инженерной инфраструктуре, в том числе к системе теплоснабжения. 
Подключение объекта к тепловым сетям — часть процесса технологического 
присоединения. Для каждого нового объекта необходимо определить место подключения 
и маршрут прокладки тепловой сети в условиях плотной городской застройки. 
При проектировании учитывается потребность каждого здания в тепловой энергии. Если 
несколько объектов подключаются совместно, на участках сети, по которым тепло поступает 
сразу к нескольким зданиям, учитывается их суммарная потребность. От этого зависит 
необходимый диаметр трубопровода. 
При выборе маршрута новой сети также учитывается существующая городская среда. 
На пути могут находиться природные и озеленённые территории, существующие здания 
и сооружения, дороги, линии метро и другие подземные коммуникации. Для разных объектов 
действуют свои ограничения и условия пересечения. 
При подключении сразу нескольких перспективных объектов капитального строительства 
(ОКС) число возможных вариантов быстро растёт: объекты можно подключать по отдельности 
или совместно, выбирать разные места присоединения к существующей сети и разные маршруты. 
Ручной поиск и сравнение таких вариантов требуют значительных трудозатрат. Автоматизация 
ускоряет эту работу. 
1.1. Как инженер формирует вариант подключения 
Тепло передаётся по двум трубопроводам. По подающему трубопроводу нагретая вода идёт 
от источника к потребителю, по обратному возвращается к источнику. На карте эта пара обычно 
показывается одной линией. Оба трубопровода на одном участке имеют одинаковый условный 
диаметр (типовой размер трубопровода). 
Сначала инженер определяет, где новая сеть должна подойти к подключаемому ОКС. 
Индивидуальный тепловой пункт (ИТП), через который здание подключается к системе 
теплоснабжения, находится внутри здания. Для предварительного построения трассы достаточно 
определить точку подключения на границе ОКС, не уточняя положение ИТП внутри здания. 
В конкурсном наборе точка подключения передаётся в составе исходных данных. 
Затем инженер выбирает место присоединения новой сети к существующей — точку врезки. 
Врезку можно выполнить в существующей тепловой камере (подземном сооружении 
с оборудованием и соединениями трубопроводов) либо непосредственно в трубопроводе. 
Если подходящей камеры в выбранном месте нет, для присоединения может потребоваться 
строительство новой. 
После этого определяется маршрут от существующей сети к подключаемым объектам. 
Несколько ОКС не обязательно подключать отдельными трассами: на части пути они могут 
использовать общий участок сети, который дальше разделяется на отдельные направления.

При выборе маршрута инженер учитывает существующую застройку, дороги, природные 
объекты и инженерные коммуникации. Одни препятствия приходится обходить, другие можно 
пересечь при соблюдении установленных требований, а для некоторых нужны специальные 
инженерные решения. 
После формирования маршрута определяется расход теплоносителя на каждом участке. 
Если участок обеспечивает несколько ОКС, учитывается их суммарный расход. Чем больше 
расход, тем больший условный диаметр может потребоваться. 
Длина трассы — не единственный критерий сравнения. Более короткий маршрут может 
оказаться сложнее или дороже из-за неудачного места присоединения, препятствий  
или необходимости строительства дополнительных сооружений. 
1.2. Задача автоматизации 
Нужно разработать сервис, который выполняет эту работу автоматически: обрабатывает 
все перспективные ОКС, строит варианты новой тепловой сети, выбирает точки врезки, 
рассчитывает расходы, подбирает условные диаметры, определяет необходимую реконструкцию 
существующей сети и сравнивает найденные решения. 
Сервис должен формировать результат без ручного исправления построенных маршрутов. 
 
2. Описание задачи 
2.1. Что нужно разработать 
Разработайте сервис автоматического построения вариантов подключения перспективных 
ОКС к существующей тепловой сети. 
На вход сервис получает один совмещённый файл GeoJSON, содержащий данные 
о существующей тепловой сети, тепловых камерах, перспективных и существующих ОКС, точках 
подключения перспективных ОКС и пространственных ограничениях. Для каждого типа объекта 
задаётся свой обязательный атрибутивный состав. 
Вместе с кейсом передаётся техническое приложение с формализованными правилами, 
справочными значениями и параметрами, необходимыми для расчёта. 
В исходных данных могут встречаться: 
• существующие здания и территории с ограничениями на размещение тепловых сетей; 
• природные и озеленённые территории; 
• автомобильные дороги; 
• трамвайные и железнодорожные пути; 
• объекты метрополитена; 
• реки и другие водные преграды; 
• газопроводы; 
• силовые кабели; 
• водопровод, канализация и другие инженерные коммуникации;

• опоры, сооружения и другие объекты городской инфраструктуры. 
Конкретный конкурсный набор может содержать только часть перечисленных типов.  
Для каждого типа, включённого в набор, заранее задаётся правило его учёта. 
Сервис определяет, какие ОКС подключать совместно, строит новую сеть, выбирает точки 
врезки, рассчитывает расходы, подбирает условные диаметры, определяет необходимую 
реконструкцию существующей сети и сравнивает варианты. 
Способ решения команда выбирает самостоятельно. Можно использовать графовые 
алгоритмы, математическую оптимизацию, вычислительную геометрию, эвристические методы 
или их сочетание. 
2.2. Базовая модель 
В задаче есть следующие упрощения: 
• используется один источник тепловой энергии, ограничение по его мощности 
не рассматривается; 
• существующая сеть связана с источником; 
• для каждого существующего участка передаются условный диаметр, существующий 
расчётный расход и ID следующего существующего объекта по направлению к источнику; цепочка 
может проходить через участки сети и камеры и заканчивается источником; 
• для каждого перспективного ОКС передаются тепловая нагрузка и готовый расчётный 
расход, т/ч; для расчёта новой сети используется расход; 
• одна линия на карте представляет пару подающего и обратного трубопроводов одного 
условного диаметра; 
• каждая отдельная часть новой сети присоединяется к существующей сети в одной точке; 
• от точки врезки до каждого подключённого ОКС должен быть только один путь — 
сеть не должна образовывать замкнутый маршрут, позволяющий подойти к одному объекту с двух 
сторон; 
• для целей кейса вся проектируемая сеть считается магистральной, отдельный тип участка 
«тепловой ввод» к зданию не выделяется; 
• в обязательной части маршрут строится в двумерном виде; глубина учитывается 
в отдельной дополнительной задаче; 
• базовый способ прокладки — подземная бесканальная прокладка, при которой трубы 
размещаются непосредственно в грунте; 
• надземная прокладка не рассматривается; 
• по направлению к источнику условный диаметр существующей сети не уменьшается;  
в конкурсной модели при движении к источнику пропуск ная способность существующей сети 
также считается не уменьшающейся, полный гидравлический расчёт не выполняется.

2.3. Структура новой сети 
Новая сеть может объединять несколько перспективных ОКС. На общем участке 
учитывается суммарный расход подключённых  через него объектов, а после разделения сети 
расход по отдельным направлениям уменьшается. 
Разветвления выполняются в тепловых камерах. К одной тепловой камере может примыкать 
не более четырёх участков тепловой сети: один участок по направлению к источник у и не более 
трёх участков в остальных направлениях. Для существующей камеры при выборе точки врезки 
учитываются уже примыкающие к ней участки. 
Если врезка не выполняется в существующей тепловой камере по правилам технического 
приложения, в точке врезки предусматривается новая тепловая камера. 
На маршруте также могут использоваться технические узлы — служебные точки, в которых 
меняется условный диаметр, способ прокладки или другой параметр участка. Технический узел 
не является тепловой камерой и сам по себе отдельной стоимости не имеет. 
Новые участки строятся прямыми отрезками, соединёнными поворотами. Геометрия трассы 
должна быть рациональной и не содержать необоснованных изломов, зигзагообразных  
и ступенчатых фрагментов. 
Новые участки не должны пересекаться между собой вне общего узла. Если два маршрута 
пересекаются, их нужно объединить в общую сеть либо перестроить. 
2.4. Расходы и условные диаметры 
Расчётный расход каждого перспективного ОКС передаётся готовым в т/ч. 
Если по новому участку тепло поступает к нескольким ОКС, их расходы складываются. 
Подающий и обратный трубопроводы имеют одинаковый расход, поэтому при расчёте 
используется расход только подающего трубопровода. 
Для каждого участка по расчётному расходу выбирается минимальный подходящий 
условный диаметр. Допустимые значения и соответствующая им пропускная способность 
задаются в техническом приложении. 
В реальной тепловой сети гидравлические потери зависят в том числе от диаметра и длины 
трубопровода: чем меньше диаметр и чем больше длина, тем выше гидравлическое сопротивление 
и потери давления. 
Полный гидравлический расчёт в кейсе не выполняется. Вместо него для каждого условного 
диаметра задаётся предельная допустимая длина непрерывной части новой сети. 
Пока условный диаметр не меняется, длина последовательных участков учитывается 
совместно. Установка тепловой камеры или технического узла сама по себе не начинает новый 
отсчёт. При смене условного диаметра начинается новый отсчёт. 
2.5. Проверка существующей сети и реконструкция 
При подключении необходимо проверить, сможет ли существующая сеть принять 
дополнительный расход от новых потребителей. Полный гидравлический расчёт существующей

сети в кейсе не выполняется; вместо него используется упрощённая расчётная модель 
реконструкции по расходам и условным диаметрам. 
Дополнительный расход от каждой точки врезки добавляется к существующему расчётному 
расходу участка, в который выполнена врезка, и далее ко всем участкам существующей сети по 
направлению к источнику. Если через один существующий участок проходит дополнительный 
расход от нескольких новых подключений, эти расходы суммируются. 
Для каждого затронутого участка существующей сети по итоговому расходу выбирается 
минимальный подходящий условный диаметр по тем же значениям пропускной способности, 
которые используются для новой сети. 
Если требуемый условный диаметр не превышает существующий, реконструкция участка не 
требуется. Если превышает, участок считается подлежащим реконструкции до требуемого 
условного диаметра. 
В рамках конкурсной модели геометрия существующей сети при реконструкции не 
изменяется и новый маршрут для неё не строится. Для расчёта реконструкции используется 
существующая геометрия участка; правила расчёта стоимости приведены в техническом 
приложении. 
Если врезка выполняется в существующей тепловой камере, дополнительно проверяется 
необходимость её реконструкции по правилам технического приложения. 
2.6. Пространственные ограничения 
Для каждого типа пространственного ограничения в техническом приложении задаётся 
правило его учёта: запрет либо условия допустимого пересечения, минимальные расстояния, угол 
пересечения и условия специального прохода. 
В зависимости от объекта новая сеть должна: 
• обойти его; 
• выдержать минимальное расстояние; 
• пересечь его при заданных условиях; 
• пересечь его с применением специального прохода. 
При специальном проходе соответствующая часть маршрута выделяется отдельным 
участком новой сети, для которого задаются специальные условия прокладки. 
Во входных данных для пространственного ограничения передаются его тип и геометрия. 
Сервис применяет к объекту правило, установленное для этого типа в техническом приложении. 
2.7. Стоимость 
Стоимость используется для сравнения вариантов. 
Учитываются: 
• новые участки сети; 
• новые тепловые камеры;

• врезки в существующую сеть; 
• прохождение пространственных ограничений; 
• реконструкция участков существующей тепловой сети, если после подключения новых 
ОКС их пропускной способности недостаточно; 
• реконструкция существующих тепловых камер, используемых для врезки, 
если она требуется. 
Стоимость нового участка зависит от его длины, условного диаметра и способа прокладки. 
Если для прохождения препятствия на части маршрута используется другой способ 
прокладки, для этой части применяется расчёт стоимости специального прохода. 
Конкретные значения и правила расчёта задаются в техническом приложении. 
2.8. Варианты и ранжирование 
Сервис формирует основной вариант и может предложить ещё до двух содержательно 
отличающихся вариантов. 
Вариант считается отличающимся, если меняются, например: 
• точка врезки; 
• объединение ОКС в общую сеть; 
• маршрут; 
• разделение на несколько отдельных частей новой сети; 
• способ прохождения ограничения, если допускаются разные решения. 
Небольшое смещение одной и той же трассы отдельным вариантом не считается. 
Все сформированные варианты рассматриваются в одном списке. 
Расчётная стоимость варианта включает стоимость новых участков тепловой сети, 
строительства новых тепловых камер, врезок, реконструкции существующих линейных участков и, 
при необходимости, существующих тепловых камер, а также штраф за перспективные ОКС,  
для которых маршрут не найден. Варианты ранжируются по показателю, в котором вес расчётной 
стоимости составляет 70 %, а вес общей протяжённости линейных строительных работ — 30 %. 
В протяжённость включаются новые и реконструируемые участки тепловой сети. Чем меньше 
значение показателя, тем выше располагается вариант. Формула расчёта приведена 
в техническом приложении. 
2.9. Если автоматический маршрут не найден 
Конкурсный набор подготавливается так, чтобы все перспективные ОКС можно было 
подключить при соблюдении правил кейса. 
Несмотря на это, сервис должен обрабатывать случай, когда для отдельного ОКС 
автоматический маршрут не найден.

В таком случае построенная для остальных объектов часть результата сохраняется, 
а отдельно выводится перечень ID перспективных ОКС, для которых маршрут не найден 
автоматически. 
Отсутствие автоматически найденного маршрута не означает, что подключение объекта 
технически невозможно в принципе. 
2.10. Результат работы сервиса 
Сервис должен предоставить: 
• новые участки сети с расходом, условным диаметром, длиной, способом прокладки 
и стоимостью; 
• точки врезки; 
• новые тепловые камеры; 
• технические узлы в местах смены параметров участков; 
• сводную информацию и общую стоимость по каждому варианту; 
• перечень ID перспективных ОКС, для которых маршрут не найден автоматически, 
если такие есть; 
• участки существующей тепловой сети, требующие реконструкции, с указанием исходного 
и требуемого условных диаметров, дополнительного расхода, длины и расчётной стоимости 
реконструкции; 
• существующие тепловые камеры, требующие реконструкции, с указанием исходного 
и требуемого условных диаметров и расчётной стоимости реконструкции; 
• выгрузку результата в один совмещённый файл GeoJSON с обязательными атрибутами. 
Подробная структура выходных данных задаётся в техническом приложении. 
2.11. Обязательный функционал 
Сервис должен: 
• обрабатывать все перспективные ОКС за один запуск; 
• автоматически выбирать точки врезки; 
• определять совместное или раздельное подключение ОКС и построить новую сеть; 
• соблюдать правила формирования сети, пространственные ограничения и требования 
к геометрии трассы;

ПРИЛОЖЕНИЕ. 
Трассировка тепловой сети с учётом глубины. 
Дополнительная задача к конкурсному кейсу «Лидеры цифровой трансформации» 2026 
 
1. Назначение дополнительной задачи 
В основной задаче маршрут новой тепловой сети строится в плоскости. В дополнительной 
задаче сервис строит маршрут с учётом глубины: новая сеть должна не только обходить 
ограничения на карте, но и правильно проходить выше или ниже существующих коммуникаций. 
Это самостоя тельная задача, а не проверка маршрута, уже построенного только  
в плоскости. Маршрут в плане может измениться, если другой путь позволяет проще и дешевле 
пройти существующие коммуникации по глубине. 
Все правила основного кейса сохраняются, в том числе правила выбора оптимальной точки 
врезки, подбора условного диаметра, предельной допустимой длины сети одного условного 
диаметра и устройства тепловых камер. 
 
2. Что нужно сделать 
Построить схему подключения перспективных ОКС к существующей тепловой сети с учётом 
положения трассы в плане и по глубине. Сервис выбирает маршрут, глубину новых участков, 
способ прохождения пересечений и рассчитывает стоимость с учётом заглубления. 
Для расчёта используется условная горизонтальная поверхность земли с отметкой Z = 0. 
Чем ниже расположена сеть, тем больше глубина и тем меньше значение Z. 
 
3. Упрощения и допущения 
1. Поверхность земли. Рельеф не учитывается. Поверхность земли считается 
горизонтальной на всей территории. 
2. Глубина существующих коммуникаций. Фактические высот ные отметки отсутствуют.  
Для каждого типа коммуникаций с кейсом передаётся одна условная глубина. 
3. Пересечения существующих коммуникаций между собой. При условных глубинах 
существующие коммуникации пересекаются между собой на одном уровне, в том числе 
существующие тепловые сети. Их взаимное положение не проверяется. Проверяется только 
положение новой тепловой сети относительно существующих коммуникаций. 
4. Вертикальные правила пересечений. С кейсом передаётся готовый справочник правил 
для разных типов коммуникаций: допустимое положение новой сети и минимальные расстояния. 
5. Габарит новой тепловой сети. Для каждого условного диаметра и способа прокладки 
задаются расчётные ширина и высота. Они учитываются при проверке возможности пройти выше 
или ниже существующей коммуникации.

6. Геология и грунтовые воды. Не учитываются. Грунты считаются одинаковыми  
и пригодными для прокладки на всей территории. 
 
4. Правила работы с глубиной 
1. Для каждого условного диаметра и способа прокладки в справочнике задаётся 
минимально допустимая глубина новой сети. 
2. Глубина выбирается с шагом 0,5 м. Минимальная и максимальная глубины задаются 
параметрами. 
3. В месте пересечения новая тепловая сеть должна пройти выше или ниже существующей 
коммуникации по правилам справочника и выдержать установленное расстояние. 
4. Если справочник допускает оба варианта — сверху и снизу, сервис выбирает вариант  
с меньшей итоговой стоимостью. 
5. Переход между разными глубинами выполняется прямым наклонным участком.  
Полный расчёт продольного профиля и конструктивное решение такого перехода не требуются. 
6. Если допустимый маршрут в заданном диапазоне глубин не найден, проблемный ОКС  
или часть маршрута отмечается как требующая ручной проработки. 
 
5. Стоимость 
Чем глубже прокладывается сеть, тем выше её расчётная стоимость. С кейсом передаётся 
готовая таблица стоимости или коэффициентов с шагом глубины 0,5 м. 
Для каждой части маршрута применяется значение, соответствующее её глубине. 
Остальные правила расчёта стоимости остаются такими же, как в основном кейсе. 
 
6. Дополнительные исходные данные 
1. Условная глубина каждого типа существующих коммуникаций. 
2. Условная глубина существующей тепловой сети. 
3. Справочник вертикальных правил пересечения и минимальных расстояний. 
4. Справочник габаритов новой сети: условный диаметр, способ прокладки,  
расчётная ширина, расчётная высота и минимальная глубина. 
5. Таблица стоимости или коэффициентов по глубине с шагом 0,5 м. 
6. Минимальная и максимальная глубины, доступные для поиска. 
7. Обязательный атрибутивный состав входных и выходных сущностей.
